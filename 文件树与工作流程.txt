二、四个 py 文件职责与输入输出
--------------------------------------------------------------------------------

2.1 dataset.py
--------------
核心类: BUVFolderDataset

- 目录约定:
  root_dir/
    benign/<video_id>/*.png|jpg|jpeg
    malignant/<video_id>/*.png|jpg|jpeg

- 主要职责:
  1) 扫描 benign / malignant 下每个 video_id 文件夹并建立 samples
  2) 训练模式: segment 级随机 anchor 采样（每段取连续 F 帧）
  3) 测试模式: segment 级中心 anchor 采样（可复现）
  4) 影像处理: resize +（可选）垂直翻转 +（可选）小角度旋转 + normalize

- 数据形状:
  输出 clip = [S, F, C, H, W]
  其中 S=segment_count, F=frames_per_segment, C=3

- 增强策略（当前代码）:
  允许: VFlip、离散旋转角度 (-15, -10, -5, 5, 10, 15)
  不使用: HFlip、随机裁剪、颜色扰动、尺度 jitter


2.2 model.py
------------
核心模块:
1) topk_softmax(scores, k)
2) SegmentQualityMLP
3) VideoClassifier

- VideoClassifier 输入:
  x: [B, S, F, C, H, W]

- 主干特征:
  可用 torchvision 或 timm 的 ConvNeXt-Tiny
  train.py 当前配置使用 timm: convnext_tiny.fb_in22k（pretrained=True）

- 前向逻辑:
  1) 展平视频帧到 [B*S*F, C, H, W]
  2) ConvNeXt 提取帧特征，重排为 [B, S, F, D]
  3) frame_head 产生 frame_logits: [B, S, F, num_classes]
  4) 对每段按帧平均得 seg_tokens: [B, S, D]
  5) quality_head 得到 seg_scores: [B, S]
  6) topk_softmax 仅保留前 k 段并归一化为 seg_w
  7) 加权聚合段特征得 video_feat，再经 video_head 输出 video_logits: [B, num_classes]

- 设计重点:
  QMIL 通过 segment quality 分数进行 top-k 段筛选，减少低质量片段干扰。


2.3 loss.py
-----------
核心函数: combined_loss(frame_logits, video_logits, labels, ...)

- 输入:
  frame_logits: [B, S, F, C]
  video_logits: [B, C]
  labels: [B]

- 计算:
  1) 帧级损失: 将 [B,S,F,C] 展平成 [B*S*F,C] 后做 CE（sum，再除样本数）
  2) 视频级损失: video_logits 对 labels 做 CE（mean）
  3) 总损失: total = frame_weight * frame_loss_avg + video_loss

- 返回:
  total_loss, frame_loss_avg.item(), video_loss.item()


2.4 train.py
------------
核心职责: 执行 3-fold 交叉验证训练，按 epoch 覆盖保存 last checkpoint，并以最后一轮结果汇总报告。

- 关键配置:
  DATA_ROOT = "/data/niyit/Miccai 2022 BUV Dataset/rawframes"
  SAVE_DIR = "cross_val_results_last_epoch"
  SEGMENTS=6, FRAMES_PER_SEG=3, IMG_SIZE=224
  N_FOLDS=3, EPOCHS=50
  BATCH_SIZE=8, LR=1e-4, WEIGHT_DECAY=1e-3

- 评估指标:
  AUC、F1、Sensitivity、Specificity、Accuracy
  同时报告 threshold=0.5 与 Youden 最优阈值两套结果


三、完整执行流程（从 python train.py 开始）
--------------------------------------------------------------------------------

Step 0. 环境与随机性初始化
- 设定随机种子（python / numpy / torch / cuda）
- 设定 GPU 可见设备与 DEVICE
- 启用 cudnn.benchmark 与 matmul precision（可用时）

Step 1. 建立全量索引（不训练）
- 先创建一个 full_dataset（augment=False, test_mode=False）
- 从 full_dataset 取:
  - all_video_ids
  - all_labels
- 用于后续 StratifiedKFold 分层切分

Step 2. 3-fold 分层切分
- 使用 StratifiedKFold(n_splits=3, shuffle=True, random_state=SEED)
- 保证每个 fold 的良恶性比例尽量一致

Step 3. 进入每个 fold 的训练
- 3.1 构建数据集
  - train_dataset:
    augment=True, test_mode=False, 启用 VFlip + Rotation
  - val_dataset:
    augment=False, test_mode=True, 关闭增强（中心采样）

- 3.2 构建 DataLoader
  - train_loader: batch_size=8, shuffle=True
  - val_loader: batch_size=1, shuffle=False

- 3.3 计算类别权重（仅视频级）
  - 统计 train_dataset 标签分布
  - 得到 class_weights_video（传给 combined_loss）
  - frame 级权重当前设为 None

- 3.4 建模与优化器
  - model = VideoClassifier(backbone_source="timm", topk=2, video_dropout=0.5)
  - optimizer = AdamW
  - scheduler = CosineAnnealingLR
  - scaler = torch.amp.GradScaler（AMP）

Step 4. epoch 训练循环（1..50）
- 对每个 batch:
  1) 前向: frame_logits, video_logits = model(videos)
  2) 损失: combined_loss(..., frame_weight=0.5, class_weights_video=...)
  3) 反向: scaler.scale(loss).backward()
  4) 梯度裁剪: clip_grad_norm_(max_norm=1.0)
  5) 参数更新: scaler.step + scaler.update

- 每个 epoch 结束后:
  1) 在 val_loader 推理 video 概率（正类 softmax）
  2) 计算 AUC 与两套阈值指标（@0.5 / @Youden）
  3) 写入内存 history
  4) scheduler.step()
  5) 覆盖保存 foldX/last.pth（只保留最后一轮）

Step 5. fold 最终评估（LAST EPOCH ONLY）
- 读取 foldX/last.pth
- 再跑一次验证集，得到 final:
  - final_eval_auc_last
  - final_eval@0.5
  - final_eval@youden
- 产出文件:
  - foldX/history.json
  - foldX/results_last.json

Step 6. 跨 fold 汇总
- 对 3 个 fold 的指标计算 mean/std
- 输出总表:
  SAVE_DIR/cross_validation_summary_last.json


四、数据流与张量形状总览
--------------------------------------------------------------------------------

单个样本视频（dataset）
  原始帧 -> 采样 S 段，每段 F 帧 -> clip [S,F,C,H,W]

训练批次（dataloader）
  [B,S,F,C,H,W] -> model

模型内部（model）
  [B,S,F,C,H,W]
    -> 展平 [B*S*F,C,H,W]
    -> ConvNeXt 特征 [B*S*F,D]
    -> 重排 [B,S,F,D]
    -> frame_head -> frame_logits [B,S,F,2]
    -> 段聚合 + quality scoring -> seg_scores [B,S]
    -> topk_softmax -> seg_w [B,S]
    -> 加权和 -> video_feat [B,D]
    -> video_head -> video_logits [B,2]

损失（loss）
  frame_logits + video_logits + labels
    -> combined_loss
    -> total_loss（用于反向）
